JSON Operating System for the Web

A lightweight framework for building decentralized applications with JSON-LD. Read and write Linked Data with a simple, familiar API.

Get Started View on GitHub
app.js 
import { JsonOS } from 'jsonos';

// Initialize with your data source
const os = new JsonOS({
  storage: 'https://pod.example/data/'
});

// Read JSON-LD data
const tasks = await os.read('/todos.json');

// Write with automatic format handling
await os.write('/todos.json', tasks);

Why jsonos?

🔗

Linked Data Native

Built for JSON-LD from the ground up. Automatic context handling, predicate expansion, and format detection.

🌐

Decentralized Ready

Works with Solid pods, static files, or any HTTP endpoint. Your data stays under your control.

🪶

Lightweight

Zero dependencies. Under 5KB gzipped. Works in browsers and Node.js without configuration.

🔄

Format Agnostic

Preserve + Layer pattern: read any RDF format while keeping original data intact.

🔐

Auth Built-in

Solid OIDC authentication ready. Seamlessly switch between authenticated and public data.

⚡

Developer Experience

Familiar async/await API. TypeScript types included. Comprehensive error messages.
