Embed Panes

Add beautiful schema.org renderers to any HTML page with one script tag.

Quick Start

Add JSON-LD to your page, then include the embed script:

<!-- Your JSON-LD data -->
<script type="application/ld+json">
{
  "@context": { "schema": "http://schema.org/" },
  "@id": "#me",
  "@type": "schema:Person",
  "schema:name": "Marie Curie",
  "schema:jobTitle": "Physicist"
}
</script>

<!-- One line to render it -->
<script src="https://jsonos.com/examples/embed.js"></script>

That's it! The script auto-detects the schema.org type and renders the appropriate pane.

Options

Configure with data attributes on the script tag:

Attribute Description Default
data-target CSS selector for container element Auto-creates after JSON-LD
data-subject Subject ID to render First @id found
data-theme "light" or "dark" light

Example with Options

<div id="my-pane"></div>

<script type="application/ld+json">
{ ... }
</script>

<script
  src="https://jsonos.com/examples/embed.js"
  data-target="#my-pane"
  data-theme="dark"
></script>

Supported Types

20 schema.org types are supported:

Person, Event, Article, Organization, Recipe, Product, Place, Movie, Book, Review, FAQPage, HowTo, JobPosting, LocalBusiness, Service, Course, VideoObject, MusicRecording, SoftwareApplication, CreativeWork

How It Works

The embed script:

  1. Finds the JSON-LD on your page
  2. Detects the @type
  3. Loads the matching pane renderer
  4. Renders into the target element
