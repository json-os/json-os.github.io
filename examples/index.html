JSON-LD → Beautiful UI

Add schema.org data to your HTML.
Get a beautiful rendered view instantly.

<script type="application/ld+json">
{
  "@type": "schema:Person",
  "name": "Marie Curie",
  "jobTitle": "Physicist",
  "description": "Nobel Prize winner"
}
</script>
→

Marie Curie

Physicist
Nobel Prize winner

Same data Google uses for rich snippets.
Same tech as SolidOS panes.
Works in any HTML page. Zero build step.
